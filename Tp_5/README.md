# TP5 — Java RMI

**Mohamed Kchaou** · LSI 3 · Développement d’applications réparties

Le TP5 met en pratique Java RMI pour appeler des méthodes distantes. La première activité expose un convertisseur de devises ; la seconde ajoute un service bancaire et compare la recherche directe du service avec JNDI.

## Activités

- [Activité 5-1 — Conversion de devise](./Activite_1/README.md) : appel distant d’un service de conversion EUR vers DT.
- [Activité 5-2 — Gestion de comptes bancaires](./Activite_2/README.md) : création et consultation de comptes, avec les versions avec et sans JNDI.

## Progression

Les deux activités utilisent un registre RMI pour publier les objets distants. L’activité 5-2 ajoute une couche de nommage JNDI et conserve les commits des deux versions pour consultation.
