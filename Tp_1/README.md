# TP1 — Sockets TCP

**Mohamed Kchaou** · LSI 3 · Développement d’applications réparties

Ce dossier présente la progression du TP1 : établir une connexion TCP, échanger des valeurs, puis réaliser des opérations entre machines sur le réseau.

## Activités

- [Activité 1-1 — Première connexion client/serveur](./Activite_1-1/README.md) : ouverture d’une connexion TCP sur le port `1234`.
- [Activité 1-2 — Échange d’entiers](./Activite_1-2/README.md) : le client envoie des entiers et le serveur renvoie leur produit par 5, jusqu’à la valeur d’arrêt `0`.
- [Activité 1-3 — Calculatrice sur le réseau](./Activite_1-3/README.md) : choix de l’adresse du serveur et calcul à distance avec quatre opérations.

## Progression

Les deux premières activités utilisent un client et un serveur lancés sur la même machine. La troisième permet de configurer l’adresse IP du serveur pour communiquer sur le réseau local.
